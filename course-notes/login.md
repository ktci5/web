## 멀티 유저 시스템

리눅스는 **여러 사람이 동시에 쓰도록** 만들어졌습니다. 그래서 파일마다 주인이 있고
권한이 나뉩니다. 크게 두 종류입니다.

| | 누구 | 무엇을 할 수 있나 |
| --- | --- | --- |
| **root** | 관리자 | 전부. 시스템을 망가뜨리는 것도 포함 |
| 일반 사용자 | 나머지 | 자기 파일과 허락된 것만 |

프롬프트 끝 글자로 구분할 수 있습니다.

```
[root@server ~]#     ← # 이면 root
[user1@server ~]$    ← $ 이면 일반 사용자
```

**`#` 이 보이면 조심하세요.** 그 상태에서는 `rm -rf /` 같은 명령도 그대로 실행됩니다.

## 접속 방법

| 방식 | 설명 |
| --- | --- |
| 그래픽 로그인 | 데스크톱 화면 |
| **가상 터미널** | 그래픽 없이 텍스트 화면 |
| 로컬 로그인 | 그 컴퓨터 앞에서 직접 |
| **원격 로그인** | `ssh` 로 네트워크 너머에서 |

어느 방식이든 **로그인 ID 와 비밀번호**로 인증합니다.

### 가상 터미널

리눅스는 텍스트 터미널을 **여섯 개** 제공합니다.

```
Ctrl + Alt + F2 ~ F7     텍스트 터미널 6개
Ctrl + Alt + F1          그래픽 모드
```

그래픽 화면이 멈췄을 때 `Ctrl+Alt+F2` 로 빠져나와 문제를 해결할 수 있습니다.
서버 실습에서 화면이 얼었을 때 재부팅 대신 시도해볼 방법입니다.

### 원격 접속

실무에서는 거의 `ssh` 입니다. 서버가 옆에 있는 경우가 없기 때문입니다.

```bash
$ ssh user1@192.168.0.10
$ ssh -p 2222 user1@server.example.com     # 포트가 다를 때
```

`telnet` 과 `rlogin` 은 **암호가 그대로 흘러가** 요즘은 쓰지 않습니다.

## 사용자 바꾸기 — su

```bash
$ su                # root 로 (비밀번호 필요)
$ su -              # root 로, 환경까지 전부
$ su - user2        # user2 로
$ exit              # 원래 사용자로 돌아오기
```

**`-` 가 있고 없고가 다릅니다.**

| | 무엇이 바뀌나 |
| --- | --- |
| `su` | 사용자만 바뀜. 환경 변수와 현재 디렉터리는 그대로 |
| `su -` | **로그인한 것처럼** 환경 전체가 바뀜 (`PATH`, 홈 디렉터리) |

`su` 로 root 가 됐는데 명령을 못 찾는다면 `PATH` 가 이전 사용자 것이기 때문입니다.
**보통 `su -` 를 쓰세요.**

### sudo 와의 차이

| | `su` | `sudo` |
| --- | --- | --- |
| 필요한 비밀번호 | **대상 계정의** 비밀번호 | **내** 비밀번호 |
| 지속 | 나갈 때까지 계속 | 명령 하나만 |
| 기록 | 남기 어려움 | 누가 뭘 했는지 로그에 남음 |

실무에서는 **root 비밀번호를 공유하지 않고 `sudo` 를 쓰는 편**이 안전합니다.
누가 무엇을 했는지 추적되기 때문입니다.

## 내가 누구인지 확인하기

```bash
$ whoami                # 지금 사용자 이름
$ id                    # 사용자·그룹 ID 전부
$ who                   # 지금 접속한 사람들
$ who am i              # 내 접속 정보
$ w                     # 접속자와 무엇을 하는 중인지
$ last                  # 최근 로그인 기록
```

```bash
$ id
uid=1000(user1) gid=1000(user1) groups=1000(user1),10(wheel)
```

**`uid=0` 이면 root** 입니다. 이름이 root 가 아니어도 uid 가 0 이면 권한은 root 와
같습니다.

`groups` 에 `wheel` 이 있으면 `sudo` 를 쓸 수 있는 계정입니다(RedHat 계열 기준).

## 나가기

```bash
$ exit
$ logout
Ctrl + D
```

`su` 로 사용자를 바꾼 상태라면 `exit` 는 **원래 사용자로 돌아오는 것**이지
접속을 끊는 게 아닙니다. 몇 번 `su` 했는지 헷갈릴 때는 `whoami` 로 확인하세요.
