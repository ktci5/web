## 왜 vi 인가

낯설고 불편해 보이지만 **모든 리눅스에 기본으로 들어 있습니다.** 원격 서버에
접속했을 때 다른 편집기가 없는 경우가 많아, 결국 vi 를 쓰게 됩니다.

```bash
$ vi 파일명
```

연습해보고 싶다면 내장 튜토리얼이 있습니다.

```bash
$ vimtutor
```

## 세 가지 모드

vi 가 어려운 이유는 **모드**라는 개념 하나 때문입니다. 이것만 이해하면 나머지는
단순 암기입니다.

```
        ┌──────────────┐
   i,a,o│              │/ ? :
   ┌────┤   명령 모드   ├────┐
   │    │              │    │
   ↓    └──────────────┘    ↓
 편집 모드   ←─ Esc ─→   Last line 모드
```

| 모드 | 무엇을 하나 | 들어가는 법 |
| --- | --- | --- |
| **명령 모드** | 커서 이동, 삭제, 복사 | 시작하면 여기. `Esc` 로 복귀 |
| **편집 모드** | 글자 입력 | `i` `a` `o` 등 |
| **Last line 모드** | 저장, 종료, 검색·치환 | `:` `/` `?` |

**처음 열면 명령 모드입니다.** 그래서 바로 타이핑하면 글자가 안 들어가고
엉뚱한 동작을 합니다. `i` 를 눌러 편집 모드로 들어가야 합니다.

**막히면 `Esc`.** 지금 어느 모드인지 모르겠으면 `Esc` 를 두어 번 눌러
명령 모드로 돌아오면 됩니다.

### 편집 모드로 들어가는 여러 방법

| 키 | 어디서부터 입력 |
| --- | --- |
| `i` | 커서 **앞**에서 (insert) |
| `a` | 커서 **뒤**에서 (append) |
| `o` | **아래에 새 줄**을 만들고 |
| `I` | 줄 **맨 앞**에서 |
| `A` | 줄 **맨 끝**에서 |
| `O` | **위에 새 줄**을 만들고 |

대문자는 "줄 단위"라고 기억하면 편합니다. `A` 는 줄 끝에서 이어 쓸 때
자주 쓰게 됩니다.

## 커서 이동

화살표도 되지만, 손을 옮기지 않는 `hjkl` 이 빠릅니다.

| 키 | 이동 |
| --- | --- |
| `h` `j` `k` `l` | 왼쪽 · 아래 · 위 · 오른쪽 |
| `0` (숫자 영) | 줄 맨 앞 |
| `^` | 줄에서 **공백이 아닌** 첫 글자 |
| `$` | 줄 끝 |
| `G` | 파일 마지막 줄 |
| `nG` 또는 `:n` | **n번째 줄로** |
| `Ctrl-F` | 한 화면 앞으로 |
| `Ctrl-B` | 한 화면 뒤로 |
| `Ctrl-L` | 화면 다시 그리기 |

**`:숫자` 를 기억해두세요.** 에러 메시지가 "42번째 줄" 이라고 알려줄 때
`:42` 로 바로 갑니다.

## 삭제

| 명령 | 지우는 범위 |
| --- | --- |
| `x` | 커서 위치의 한 글자 |
| `dw` | 커서부터 단어 끝까지 |
| `dd` | **줄 전체** |
| `D` | 커서부터 줄 끝까지 |
| `:n,nd` | n번째 줄부터 n번째 줄까지 |

```
:5,10d       5번째 줄부터 10번째 줄까지 삭제
```

`dd` 를 세 번 하려면 `3dd` 처럼 숫자를 앞에 붙입니다. 다른 명령도 같습니다.

## 수정

| 명령 | 하는 일 |
| --- | --- |
| `r` | 커서 위 한 글자만 다른 글자로 |
| `R` | 덮어쓰기 모드 |
| `cw` | 단어를 지우고 편집 모드로 |
| `C` | 줄 끝까지 지우고 편집 모드로 |
| `s` | 한 글자를 지우고 편집 모드로 |
| `J` | 다음 줄을 현재 줄에 **붙이기** |
| `xp` | 커서 글자와 오른쪽 글자를 **맞바꾸기** |
| `~` | 대소문자 바꾸기 |
| **`u`** | **되돌리기** |
| `U` | 현재 줄의 변경 전부 되돌리기 |
| `.` | **직전 명령 반복** |

**`u` 와 `.` 이 가장 유용합니다.** 잘못했으면 `u`, 같은 작업을 반복하려면 `.` 입니다.

## 검색과 치환

| 명령 | 하는 일 |
| --- | --- |
| `/문자열` | 아래 방향으로 검색 |
| `?문자열` | 위 방향으로 검색 |
| `n` | 다음 결과 |
| `N` | 이전 결과 |
| `:%s/옛것/새것/g` | **파일 전체에서 모두 바꾸기** |

```
:%s/old-server/new-server/g      전부 바꾸기
:%s/old/new/gc                   바꿀 때마다 확인
:5,20s/old/new/g                 5~20번째 줄에서만
```

`%` 는 파일 전체, `g` 는 한 줄에 여러 개 있어도 전부, `c` 는 확인을 뜻합니다.

**설정 파일에서 도메인이나 포트를 일괄 변경할 때** 자주 씁니다.

## 복사와 붙여넣기

| 명령 | 하는 일 |
| --- | --- |
| `yy` | 줄 복사 (yank) |
| `p` | 커서 **아래**에 붙여넣기 |
| `P` | 커서 **위**에 붙여넣기 |
| `:n,n co n` | n~n번째 줄을 복사해 n번째 줄 뒤에 |
| `:n,n m n` | n~n번째 줄을 n번째 줄로 이동 |

```
:1,3 co 5       1~3번째 줄을 복사해 5번째 줄 뒤에
:4,6 m 8        4~6번째 줄을 8번째 줄로 이동
```

`dd` 로 지운 것도 `p` 로 붙일 수 있습니다. **잘라내기가 됩니다.**

## 저장과 종료

가장 많이 쓰는 것들입니다.

| 명령 | 하는 일 |
| --- | --- |
| `:w` | 저장 |
| `:w 새이름` | 다른 이름으로 저장 |
| `:wq` | **저장하고 종료** |
| `:x` | 저장하고 종료 (바뀐 게 있을 때만 씀) |
| `ZZ` | 저장하고 종료 (`:` 없이) |
| **`:q!`** | **저장하지 않고 강제 종료** |

**`:q!` 를 꼭 기억하세요.** 뭔가 잘못 건드렸을 때 저장하지 않고 빠져나오는
탈출구입니다. 설정 파일을 망가뜨렸을 때 이것만 알아도 됩니다.

읽기 전용 파일을 열었는데 저장하려면 `:w!` 를 시도하거나,
권한이 없으면 `sudo` 로 다시 열어야 합니다.

## 환경 설정

Last line 모드에서 `:set` 으로 바꿉니다.

| 명령 | 하는 일 |
| --- | --- |
| `:set nu` | **줄 번호 표시** |
| `:set ic` | 검색할 때 대소문자 무시 |
| `:set list` | 탭(`^I`)과 줄 끝(`$`) 같은 안 보이는 문자 표시 |
| `:set showmode` | 지금 모드 표시 |
| `:set` | 지금 설정 보기 |
| `:set all` | 모든 설정과 값 |
| `:!명령` | **vi 를 나가지 않고 셸 명령 실행** |

`:set list` 는 **YAML 이나 Makefile 을 만질 때 유용합니다.**
공백과 탭이 섞이면 문법 오류가 나는데, 눈으로는 구분이 안 되기 때문입니다.

### 매번 적용하려면

`~/.vimrc` 에 적어두면 열 때마다 자동으로 적용됩니다.

```bash
$ vi ~/.vimrc
```

```vim
set nu
set tabstop=4
set ic
set cindent
set smartindent
```

## 처음 열었을 때 순서

익숙해지기 전까지는 이 흐름만 따라 하면 됩니다.

```
1. vi 파일명       열기
2. i              편집 모드로
3. 내용 수정
4. Esc            명령 모드로
5. :wq            저장하고 종료
```

잘못 건드렸으면 `Esc` → `:q!` 로 나온 뒤 다시 시작하면 됩니다.
