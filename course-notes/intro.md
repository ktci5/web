## 유닉스에서 리눅스까지

리눅스를 이해하려면 유닉스부터 봐야 합니다. **리눅스는 유닉스를 본떠 새로 만든
운영체제**라, 명령어와 구조가 거의 같습니다.

| 연도 | 일 |
| --- | --- |
| 1969 | **유닉스 탄생** — Multics 가 좋지만 느려서, 가볍게 다시 만듦 |
| 1973 | **C 언어로 다시 작성** — 데니스 리치가 C 를 만들고 유닉스를 옮김 |
| 1980년대 | **BSD** (버클리, 연구용) 와 **상용 유닉스** 로 갈라짐 |
| 1990년대 | 표준화 — **System V R4**, ANSI-C, POSIX |
| 1991 | **리눅스 커널 등장** — 리누스 토르발스 |

### C 언어로 옮긴 것이 결정적이었습니다

처음 유닉스는 어셈블리(기계어)로 짜여 있었습니다. 그래서 **다른 컴퓨터로 옮기려면
처음부터 다시 짜야 했습니다.** C 로 다시 쓰면서 소스만 다시 컴파일하면 다른
기계에서도 돌게 됐고, 이것이 유닉스가 퍼진 이유입니다.

### POSIX

여러 유닉스가 조금씩 다르게 발전하자 **호환 기준**을 만들었습니다. IEEE 가 정한
API 표준이 POSIX 입니다. 리눅스도 이 기준을 따르기 때문에 유닉스에서 쓰던 명령이
대부분 그대로 동작합니다.

## 리눅스의 탄생

1991년, 핀란드 헬싱키 대학의 **리누스 토르발스**가 커널을 만들었습니다.
리처드 스톨먼의 FSF(자유 소프트웨어 재단)가 이끄는 **GNU** 프로젝트의
**GPL** 정책에 따라 무료로 배포됐습니다.

### GPL 이 무엇인가

조건이 붙은 자유 라이선스입니다.

- 소프트웨어는 무료
- 고쳐서 다시 파는 것도 가능
- **다만 소스 코드는 반드시 공개해야 함**

이 조건 덕분에 누구나 고쳐 쓸 수 있었고, 짧은 시간에 안정화되면서
**300개가 넘는 배포판**이 나왔습니다.

> 커널과 배포판은 다릅니다. 리누스가 만든 것은 **커널**이고,
> 우리가 설치하는 Rocky Linux 나 Ubuntu 는 커널에 여러 프로그램을 얹은 **배포판**입니다.

---

## 배포판

커널만으로는 쓸 수 없습니다. 배포판은 **커널 + 오피스 + X-Windows + 개발 도구 +
각종 유틸리티**를 묶어 바로 설치해 쓸 수 있게 만든 것입니다.

목적에 따라 갈립니다.

- 유료 / 무료
- 기업용 / 가정용
- 서버 / 데스크톱 / 임베디드
- 일반 사용자 / 파워 유저
- 범용 / 특수 목적 (방화벽, 라우터)
- 기업이 지원 / 커뮤니티가 지원

### 계열로 나누면 — 패키지 관리 방식이 기준

배포판이 많아 보여도 **소프트웨어를 어떻게 설치하고 관리하느냐**로 나누면 몇 갈래입니다.

| 계열 | 관리 도구 | 대표 배포판 |
| --- | --- | --- |
| **RedHat** | `rpm` · `yum` · `dnf` | RHEL, Fedora, CentOS, **Rocky Linux** |
| **Debian** | `dpkg` · `apt` · `snap` | Debian, **Ubuntu** |
| Slackware | `yast` | openSUSE |
| Mandrake | `rpmdrake` | Mandriva, PCLinuxOS |

**우리 과정은 Rocky Linux 를 쓰므로 RedHat 계열입니다.** 패키지 설치에 `dnf` 를
쓰고, Ubuntu 문서에 나오는 `apt-get` 은 동작하지 않습니다.

인터넷에서 찾은 설명이 안 될 때 이 차이가 원인인 경우가 많습니다.
**"이 문서가 어느 계열인가"** 를 먼저 확인하세요.

| 하고 싶은 일 | RedHat 계열 | Debian 계열 |
| --- | --- | --- |
| 설치 | `dnf install nginx` | `apt install nginx` |
| 삭제 | `dnf remove nginx` | `apt remove nginx` |
| 검색 | `dnf search nginx` | `apt search nginx` |

## 지금 쓰는 것 확인하기

```bash
$ cat /etc/*release          # 배포판과 버전
$ uname -r                   # 커널 버전
$ uname -a                   # 전부
```

이 세 줄은 **질문할 때 함께 올리면 좋은 정보**입니다. 배포판과 커널 버전만 알아도
답하는 쪽이 훨씬 정확하게 짚어줄 수 있습니다.
